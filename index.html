手机电脑同步

用你自己的 GitHub 私密 Gist 做同步中转：手机和电脑填同一个 GitHub Token，学习记录（词库、每日计划、错题、统计）双向合并同步。Token 只保存在本机浏览器，不上传给任何第三方。还没有 Token 的话，去 github.com → Settings → Developer settings → Personal access tokens 生成一个（经典 Token 勾选 gist 权限即可）。
