# 英语单词复习手册（可安装网页应用）

## 先说明
这是 PWA 版本，可以安装到 Windows/Mac 桌面，也可以添加到 Android/iPhone 主屏幕。
**安装功能需要通过 HTTPS 网站打开**（例如 GitHub Pages）；直接双击 index.html 可以浏览，但浏览器通常不会提供“安装应用”功能。

## 最简单的发布方式：GitHub Pages
1. 登录 GitHub，新建一个公开仓库，例如 `english-vocab-handbook`。
2. 解压本压缩包，把 `index.html`、`manifest.webmanifest`、`sw.js` 和 `icons` 文件夹中的内容上传到仓库根目录。
3. 打开仓库 Settings → Pages。
4. 在 Build and deployment 中选择 Deploy from a branch；Branch 选择 `main`，目录选择 `/ (root)`，保存。
5. 等待 GitHub Pages 发布，打开页面给出的 `https://...github.io/.../` 地址。

## 安装到电脑桌面
- Windows Edge/Chrome：打开已发布的网址；地址栏右侧若出现安装图标，点击安装。也可打开浏览器菜单，选择“安装此网站为应用”或“将页面安装为应用”。
- Mac Chrome/Edge：打开网址，从浏览器菜单中选择安装应用（若提供）。

## 安装到手机
- Android：用 Chrome 打开网址 → 右上角菜单 → “安装应用”或“添加到主屏幕”。
- iPhone/iPad：用 Safari 打开网址 → 分享按钮 → “添加到主屏幕” → 添加。

## 离线使用
首次在线打开并成功缓存后，页面会缓存主要文件，之后通常可以离线打开。首次安装和首次缓存需要联网。

## 更新词库
修改 `index.html` 中的数据后，重新上传覆盖仓库文件；如设备仍显示旧版，可关闭应用后重新打开，必要时清除浏览器缓存。
